# VeilCode Studio Brand Guide

## Brand Position

VeilCode Studio is a digital solutions studio for businesses that need better digital infrastructure: websites, web apps, mobile apps, AI automation systems, data analytics, and growth operations.

The brand should feel technical, direct, senior, and outcome-driven. It should avoid vague hype. The clearest theme is: complex operations made usable through strong engineering and clean interfaces.

## Color System

Primary colors:

- Brand cyan: `#00E5FF`
- Accessible cyan on light surfaces: `#00B8D4`
- Dark page: `#080A0F`
- Midnight page: `#0A0F1E`
- Light page: `#FFFFFF`
- Dark surface: `#0D1117`
- Light surface: `#F4F6F9`

Service accents:

- Web: `#00E5FF`
- Mobile: `#818CF8`
- Data: `#10D9A0`
- Social: `#F5A623`
- AI: `#C084FC`

Use cyan as the primary signal. Use the service accents to separate categories, workflow nodes, or capability areas.

## Typography

Use a clean system sans stack for most brand assets:

`Inter, Segoe UI, Arial, sans-serif`

Use a monospace stack for small labels, workflow tags, technical captions, and metadata:

`Consolas, Menlo, Monaco, monospace`

## Visual Rules

- Prefer dark or midnight backgrounds for AI automation and technical infrastructure content.
- Use light surfaces for workflow diagrams, reports, and client-facing explainers.
- Keep corners restrained: 6px to 12px in UI, larger radius only for large asset frames.
- Use grid lines, connection paths, workflow nodes, and small metadata labels as recurring motifs.
- Keep copy direct. Show the operational outcome before listing tools.

## Copy Patterns

Good headline formats:

- Turn workflows into intelligent operating systems.
- Find the work your team should never do twice.
- AI automation systems for serious operations.
- Build the system behind the service.

Avoid:

- Generic "unlock the power of AI" language.
- Overly playful startup phrasing.
- Dense paragraphs on visual assets.

## AI Automation Project Asset Use

For proposals, start with `presentation-cover.svg`, then use `workflow-card-template.svg` to map the client process. For blogs and link previews, use `ai-automation-cover.svg`. For LinkedIn, Instagram, or WhatsApp status posts, use `automation-social-square.svg`.

When creating new assets, keep these recurring elements:

- VeilCode mark in the top-left or bottom-left.
- Cyan primary accent.
- 1 to 3 supporting service colors.
- Workflow nodes connected by thin lines.
- A short technical label in monospace.
- One strong operational outcome in the headline.
