# VeilCode Brand Assets

Reusable source assets for VeilCode Studio marketing, proposals, AI automation projects, documentation, and social graphics.

## Files

- `logo-mark.svg`: standalone app/profile mark.
- `logo-horizontal-dark.svg`: full logo on dark background.
- `logo-horizontal-light.svg`: full logo on light background.
- `brand-pattern.svg`: technical background for AI and automation visuals.
- `ai-automation-cover.svg`: 1200x630 cover for Open Graph, blog, and campaign use.
- `automation-social-square.svg`: 1080x1080 social media graphic.
- `presentation-cover.svg`: 16:9 proposal or deck cover.
- `workflow-card-template.svg`: editable workflow diagram for automation projects.
- `tokens.json`: portable brand tokens for AI tools, design scripts, and docs.
- `brand.css`: CSS custom properties for external projects.

## Usage Notes

Use the dark logo on dark technical backgrounds and the light logo on white or pale UI surfaces. Keep the cyan mark visible with clear spacing around it. For AI automation materials, lead with the dark/midnight surfaces and use data green, AI violet, and mobile indigo as secondary accents.
